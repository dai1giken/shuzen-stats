# 大規模修繕統計ビューア

マンションの大規模修繕にかかわる日本の政府統計を、読める形へ並べ直した公開ページです。
数値はすべて公表値で、そこに施した計算（合計・単位換算・物価換算）も算式ごと公開しています。

**https://dai1giken.co.jp/shuzen-stats/**

GitHub Pages（`https://dai1giken.github.io/shuzen-stats/`）にも同じものが出るが、
canonical は上の本番URLを指している。本番は Bizメール&ウェブ で、公開は手動アップロード。

制作・提供：株式会社第一技研

---

## このリポジトリは何か

ページに載っている数値は、すべて国土交通省・総務省の公表値です。
このリポジトリには、**その数値をどこから取得し、どう計算して表示しているかの全部**が入っています。

ページ側で「算式と基準値をすべて公開する」と書いている以上、
その算式そのものも読める状態にしておくべきだと考えて公開しています。

## 構成

```
update_basis.py   e-Stat API から basis.json を作る（要 ESTAT_APP_ID）
      ↓
basis.json        取得した基準値と系列
      ↓
build.py          template.html にトークンを埋め、チャートSVGを計算して埋め込む
      ↓
index.html        公開されるページ
deflator/         工事種別ごとのページ（建築系31区分＋一覧）
make_ogp.py       basis.json から OGP 画像を生成
```

| ファイル | 役割 |
|---|---|
| `template.html` | ページの原本。**編集するのはここだけ** |
| `update_basis.py` | e-Stat API 3.0 からのデータ取得 |
| `build.py` | HTML の生成。トークン展開とチャート描画 |
| `cartogram.py` | 47都道府県タイルカートグラム（`TILES` が配置の定義） |
| `build_deflator.py` | 工事種別ごとのページ（`deflator/`）。建築系31区分 |
| `costfig.py` | 戸あたり工事金額のレンジ図・分布表、消費者物価との比較図 |
| `make_ogp.py` | OGP 画像（1200×630 PNG） |
| `fetch_estat.py` | 調査用。`--search` / `--meta` で統計表を探す |
| `index.html` / `page.html` / `basis.json` / `ogp.png` | **生成物。直接編集しない** |

## 手元で動かす

```bash
pip install pillow
setx ESTAT_APP_ID "e-Stat で発行した appId"   # Windows。Linux/macOS は export
python update_basis.py
python build.py
python make_ogp.py
```

`ESTAT_APP_ID` は [e-Stat の API 機能](https://www.e-stat.go.jp/api/) で無料発行できます。
**リポジトリには含まれていません。** GitHub Actions では Secrets から渡しています。

## 自動更新

`.github/workflows/update.yml` が毎月10日 07:00 JST に走り、
e-Stat から取り直してページと OGP を再生成し、GitHub Pages へ公開します。

建設工事費デフレーターは工事種別を **75区分** 持っており、`basis.json` にはその全部が入っています。
うち建築にあたる **31区分** を `deflator/` に1区分1ページで出しています。

建設工事費デフレーターと消費者物価指数は月次で更新されますが、
**建築着工統計の DB 提供は 2023年度で止まっています**（統計表の更新日は新しくても収録期間は伸びません）。

`basis.json` には取得日が入るため、実行のたびにコミットが1件入ります。
**元データが伸びたかどうかは、コミットメッセージで区別できます。**

| コミットメッセージ | 意味 |
|---|---|
| `chore: 月次更新（2026年6月 → 2026年7月）` | 元データが伸びた |
| `chore: 再生成（元データは2026年6月のまま）` | 取得日だけ更新された |

## 数値の性質について

- 秒進行のカウンターは実測ではなく、年度の確定値を経過秒で割った**按分推計**です
- 戸あたり工事金額は、実態調査の値をデフレーターで物価に置き直した**参考値**です。
  **工事金額に共通仮設費は含まれず**、換算は指数の比だけで行っており、
  仕様・規模・立地・劣化状況は反映していません
- 将来予測は掲載していません。実績値と、統計作成者自身が公表した見通しのみです
